一歩は、目標が大きく感じられるときの「最初の一歩」を手伝います。

「運動」「読書」のように短く入力すると、今すぐできる小さな行動を提案します。実行後は自己チェックで振り返り、難易度を調整できます。

主な機能
* 設定した AI モデルによる即時提案
* Markdown 資料から学習プランを作成
* 実践回数・時間・体感難易度の記録
* 直近2週間の活動と成長のまとめ
* 暗号化バックアップと復元
* 同じ Wi-Fi 上で Windows アプリと Android を直接 P2P 同期

プライバシー
* アカウント不要、分析ツールなし
* 記録は端末内にのみ保存
* API キーは Android の暗号化ストレージに保存
* AI リクエストは設定したエンドポイントにのみ送信
