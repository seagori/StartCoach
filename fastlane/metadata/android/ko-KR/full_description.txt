한걸음은 목표가 너무 크게 느껴질 때 시작을 돕습니다.

"운동", "독서"처럼 짧게 입력하면 지금 바로 할 수 있는 작은 행동을 제안하고, 실행 후 스스로 점검하며 난이도를 조절합니다.

주요 기능
* 설정한 AI 모델로 즉석 제안 받기
* 마크다운 학습 자료로 학습 경로 만들기
* 시도 횟수·시간·체감 난이도 기록
* 최근 2주 활동과 성장 요약
* 암호화 백업 및 복원
* 같은 Wi-Fi에서 Windows 앱과 Android 직접 P2P 동기화

개인정보
* 계정 없음, 분석 도구 없음
* 기록은 기기에만 저장
* API 키는 Android 암호화 저장소에 보관
* AI 요청은 사용자가 설정한 서버로만 전송
