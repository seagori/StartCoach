一小步帮你在目标看起来太大时迈出第一步。

输入“运动”“阅读”这样的简短目标，应用会建议几个现在就能做的小行动，并在完成后帮助你自查和调整难度。

主要功能
* 使用你配置的 AI 模型生成即时建议
* 根据 Markdown 资料生成学习路径
* 记录尝试次数、时长和主观难度
* 最近两周的活动与成长总结
* 加密备份与恢复
* 在同一 Wi-Fi 下与 Windows 应用直接 P2P 同步

隐私
* 无需账户，不包含分析工具
* 记录仅保存在本机
* API 密钥保存在 Android 加密存储中
* AI 请求只发送到你配置的服务器

一小步是基于 GNU GPL v3 或更高版本发布的自由软件。
