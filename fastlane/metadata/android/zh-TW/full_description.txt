一小步幫你在目標看起來太大時邁出第一步。

輸入「運動」「閱讀」這樣的簡短目標，應用程式會建議幾個現在就能做的小行動，並在完成後協助你自我檢查與調整難度。

主要功能
* 使用你設定的 AI 模型產生即時建議
* 根據 Markdown 資料建立學習路徑
* 記錄嘗試次數、時長與主觀難度
* 最近兩週的活動與成長摘要
* 加密備份與還原
* 在同一 Wi-Fi 下與 Windows 應用程式直接 P2P 同步

隱私
* 無需帳號，不含分析工具
* 紀錄僅儲存在本機
* API 金鑰儲存在 Android 加密儲存空間
* AI 請求只會傳送到你設定的伺服器

一小步是依據 GNU GPL v3 或更新版本發佈的自由軟體。
